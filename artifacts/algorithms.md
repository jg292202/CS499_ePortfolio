# Algorithms & Data Structures

The artifact I selected for the algorithms and data structures category is my original Binary Search Tree (BST) project from CS300.  The project was designed to store, search, and organize bid records loaded from a CSV file using a traditional BST structure.  While the original implementation successfully demonstrated basic tree operations such as insertion, search, and traversal, it lacked the performance guarantees and structural stability required for larger datasets.  For Milestone Three, I refactored this artifact into a fully functional AVL tree, transforming the original unbalanced BST into a self-balancing data structure capable of maintaining logarithmic performance even as the dataset grows.  This enhancement modernizes the artifact and aligns it with industry-standard algorithmic practices.

I chose this artifact for my ePortfolio because it provides a clear demonstration of my ability to evaluate and improve algorithmic solutions using proper computer science principles. The transformation from a BST to an AVL tree required implementing height tracking, balance factor calculations, and four rotation cases (LL, RR, LR, RL) to ensure the tree remains balanced after insertions and deletions.  These enhancements demonstrated my understanding of algorithmic trade-offs.  This enhancement particularly shows how balancing operations improve worst case performance from O(n) to O(log n).  I also rewrote the deletion logic to support AVL rebalancing, which required careful handling of successor nodes and subtree height updates. This artifact now reflects a significantly more advanced and efficient data structure, making it an excellent representation of my work in algorithms and data structures.

The enhancement aligns directly with the course outcomes I planned to meet in Module One, especially the outcome focused on designing and evaluating computing solutions using algorithms principles.  By implementing AVL balancing, I displayed my ability to apply computer science standards to improve performance and reliability.  I also strengthened my competency in professional-quality written communication through the documentation and narrative accompanying the artifact. 

Reflecting on the enhancement process, I learned how critical structural invariants are to the performance of tree-based data structures.  Implementing AVL balancing required a deeper understanding of recursion, height propagation, and rotation mechanics.  I gained valuable experience debugging subtle issues such as incorrect height calculations, imbalance conditions, and subtree updates.  Rewriting the deletion logic was particularly challenging because it required integrating BST removal rules with AVL rebalancing, ensuring that the tree remained structurally sound after node removal. Completing this enhancement increased my confidence in working with complex data structures and reinforced the importance of algorithmic rigor when designing scalable software solutions.
